# Penetration-Testing-Report
# Penetration Testing Report – Metasploitable 2

## 📌 Project Overview

This repository contains my **Penetration Testing Report** completed for the module:

* **Module Code:** NST 31062
* **Module Name:** Practical for Vulnerability Assessment and Penetration Testing-I
* **Assessment:** Practical Skills Assessment – Penetration Testing on Test Systems

The assessment was conducted in a **safe and controlled virtual environment** using **Kali Linux** as the testing machine and **Metasploitable 2** as the intentionally vulnerable target system.

## 🎯 Objective

The main objective of this assessment was to gain practical experience in:

* Reconnaissance and target identification
* Operating system detection
* Protocol identification
* Service and version detection
* Vulnerability assessment
* Exploitation of identified vulnerabilities
* Providing security recommendations and remediation strategies

## 🛠️ Tools Used

The following tools were used during the assessment:

* **Kali Linux**
* **Nmap**
* **Netdiscover**
* **Nessus**
* **Metasploit Framework**

## 🔍 Testing Methodology

The penetration testing process followed these main phases:

### 1. Reconnaissance

Information about the target system was collected, including:

* Target IP address identification
* Operating system detection
* Protocol identification
* Open ports and running services
* Service version detection

### 2. Vulnerability Assessment

**Nessus** was used to scan the target system and identify known vulnerabilities, weak configurations, outdated software, and weak passwords.

### 3. Exploitation

The **Metasploit Framework** was used to validate selected vulnerabilities in the controlled laboratory environment.

Examples included:

* UnrealIRCd Backdoor
* Weak VNC password
* Bind Shell Backdoor

### 4. Security Recommendations

Security recommendations were provided to reduce the identified risks, including:

* Applying regular patches and updates
* Removing vulnerable or outdated software
* Using strong passwords
* Disabling unnecessary services and ports
* Configuring firewall rules
* Using secure and updated protocols
* Monitoring systems for suspicious activity

## ⚠️ Disclaimer

This project was created **for educational purposes only**.

All penetration testing activities were performed on an intentionally vulnerable **Metasploitable 2 virtual machine** in a safe and controlled environment.

Do **not** use the techniques or tools in this repository against systems without proper authorization.
